# Bike-Sales-Lakehouse-Databricks-PySpark-SQL-Delta-Lake
# 🚲 Bike Sales Lakehouse

This repository contains an end-to-end **Data Lakehouse implementation for Bike Sales**, built using **Databricks** and following the **Medallion Architecture**.

The project covers data ingestion, transformation, data cleaning, dimensional modeling, and preparation of analytics-ready data.

## 🏗️ Architecture

This project follows the **Medallion Architecture**:

### 🥉 Bronze Layer

* Raw data ingestion
* Schema inference
* Storage as Delta tables

### 🥈 Silver Layer

* Data cleaning and standardization
* Data type casting
* Data validation
* Data transformation

### 🥇 Gold Layer

* Dimensional data modeling
* Fact and dimension tables
* Star Schema
* Analytics-ready data

## 🛠️ Technologies Used

* Databricks
* Apache Spark
* PySpark
* Spark SQL
* Delta Lake
* Unity Catalog

## 📌 Project Structure

The repository contains the datasets, Databricks notebooks, SQL scripts, and other resources used to build the Bike Sales Lakehouse.
